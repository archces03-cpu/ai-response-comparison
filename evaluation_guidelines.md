# Evaluation Guidelines

## 1. Purpose
These guidelines provide a consistent process for comparing two AI-generated responses to the same prompt.

## 2. Evaluation Process
1. Read the original prompt carefully.
2. Review both responses independently.
3. Check factual claims for accuracy.
4. Assess relevance to the user's question.
5. Check whether each response follows the instructions.
6. Evaluate clarity and readability.
7. Select the stronger response and document the reason.

## 3. Scoring Criteria
Score each criterion from 1 to 5.

- **Factual accuracy:** Are the claims correct and supported?
- **Relevance:** Does the response address the prompt?
- **Instruction-following:** Does it satisfy the requested format, length, and constraints?
- **Clarity:** Is the response understandable and well organized?

Use the project's rubric for the meaning of each score.

## 4. Choosing the Preferred Response
Choose the response that best satisfies the prompt overall. Do not automatically select the longer or more confident response.

A serious factual error may outweigh strengths in style or clarity. Explain the decision using specific evidence from the responses.

## 5. Handling Uncertainty
If a claim cannot be verified confidently, record the uncertainty rather than assuming it is true. Use reliable references when fact-checking is necessary.

## 6. Quality Checks
Before finalizing an evaluation, confirm that:
- Both responses were assessed using the same criteria.
- Scores match the written reasoning.
- The preferred response is clearly identified.
- Important factual errors and instruction violations are documented.
- The conclusion is supported by the evidence.

## 7. Professional Standard
Evaluations should be consistent, objective, transparent, and focused on response quality rather than personal preference.
